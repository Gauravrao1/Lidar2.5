# SemanticKITTI Dataset Notes

## About
SemanticKITTI provides dense point-wise semantic annotations for the KITTI Odometry Benchmark's
Velodyne HDL-64E LiDAR scans. It covers 22 sequences with ~43,500 scans total.

## Download
Full dataset requires ~80GB and academic registration:
1. **Point clouds**: http://www.cvlibs.net/datasets/kitti/eval_odometry.php → `data_odometry_velodyne.zip`
2. **Semantic labels**: http://www.semantic-kitti.org/dataset.html → `data_odometry_labels.zip` (v1.1)

## Standard Split
| Split | Sequences | Scans |
|---|---|---|
| Train | 00-07, 09-10 | 19,130 |
| Validation | 08 | 4,071 |
| Test | 11-21 | 20,351 |

## Binary Format
- `.bin`: flat float32 × 4 (x, y, z, intensity), ~1.5-2.0 MB per scan
- `.label`: flat uint32 (lower 16 bits = semantic ID, upper 16 bits = instance ID)

## Sample Data
The `sample/` subdirectory contains 10 synthetic LiDAR scans generated by
`scripts/generate_sample_data.py`. These use the same binary format as SemanticKITTI
and include all major object classes (road, buildings, cars, people, vegetation, poles).

**All metrics computed on sample data are clearly labeled as "SAMPLE RUN" in reports.**
